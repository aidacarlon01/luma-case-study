# LUMA case study – evidence

Screenshots of LUMA, FourthRev's AI learning assistant (LearnWise, inside Canvas LMS), as learners and colleagues see it.

- `index.html` – full evidence page
- `slide/index.html` – 16:9 tabbed slide for embedding
- `assets/` – screenshots (shared by both)

## Embed the slide

```html
<div style="position:relative;width:100%;max-width:1100px;aspect-ratio:16/9;">
  <iframe src="https://USER.github.io/REPO/slide/" title="LUMA in practice"
          style="position:absolute;inset:0;width:100%;height:100%;border:0;border-radius:12px;"
          loading="lazy"></iframe>
</div>
```

Add `#careers`, `#running-it` or `#data` to the `src` to open on a tab.
